# Paid trial: terms checklist

General information, not legal advice. Have the agreement reviewed; classification and IP rules vary by state and country.

Fill every line before the trial starts and send it to the candidate in writing:

| Term | What to write |
|---|---|
| Scope | One task with a clear finished state; not on the critical path of a release |
| Length | 1-3 days, or a fixed number of hours spread over a week for employed candidates |
| Rate | A fair rate for the level, paid whether or not you hire; state the amount and when it is paid |
| Paperwork | A short independent-contractor agreement for the trial |
| IP | A written assignment of the trial work to the company. Contractor code is generally not "work made for hire" without one (17 U.S.C. § 101: https://www.law.cornell.edu/uscode/text/17/101) |
| Confidentiality | A short NDA covering the codebase they see |
| Access | A sandbox or copy of the repo; no production systems, no real customer data, accounts removed at the end |
| AI rule | The same rule as the rest of the process, stated |
| Check-ins | One 15-minute call per day with a named person |
| Evaluation | The criteria headings (not the private rubric) and who decides |
| Decision date | When the candidate will hear back, within 3 business days of the trial ending |
| Employed candidates | Make sure the trial doesn't require them to break obligations to a current employer; let them choose evenings or a vacation day |

Red flags in your own design: a task you need shipped next sprint (that is a contract, not a trial); unpaid "trial days"; trials longer than 3 days before an offer; giving production credentials.
